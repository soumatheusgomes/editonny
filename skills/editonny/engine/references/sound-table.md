# Sound selection

Use this selection guide only for explicitly requested and confirmed sound effects. A visual event or transition alone does not authorize sound; leave effects off otherwise.

For requested effects, choose a sound for a visible event: soft click for interface feedback, short impact for an emphatic reveal, whoosh for a transition, rise for anticipation, or gentle confirmation for a completed action. Match the peak to the movement and avoid clutter. Inspect the library license before use.

See [WORKFLOW.md](../WORKFLOW.md) for scope, originals, source-language fidelity, and sample review.

## Helpers

Run the relevant helper with `--help` before supplying task-specific paths:

```sh
uv run --directory '<ENGINE>' python helpers/effects.py --help
uv run --directory '<ENGINE>' python helpers/make_sfx.py --help
uv run --directory '<ENGINE>' python helpers/sound_plan.py --help
```
